# Support

Use the [WordPress.org support forum](https://wordpress.org/support/plugin/wp-user-groups/)
for installation and usage questions. Use the GitHub issue tracker for
reproducible defects and narrowly scoped enhancements, and GitHub Discussions
for broader development conversations.

Report security vulnerabilities through
[GitHub's private advisory form](https://github.com/stuttter/wp-user-groups/security/advisories/new),
not in a public issue.
